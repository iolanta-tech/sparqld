# Reference documentation guidance

## Reference persona

Write for a practitioner who has chosen `sparqld` and needs an exact contract
for querying, configuring, or integrating it. They can use command-line tools
but may not know RDF or JSON-LD. State prerequisites, commands, output, and
constraints that affect use; explain unfamiliar linked-data terms when first
needed.

Keep repository development, release, and publication workflows in Project.
Codex integration documents serve a practitioner using Codex to query their
knowledge base, not a contributor testing the plugin.

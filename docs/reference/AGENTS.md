# Reference documentation guidance

## Reference persona

Write for a knowledge engineer or ontologist—personal knowledge base or project
scale—who has chosen `sparqld` and needs an exact contract for querying,
configuring, or integrating it. They have basic RDF and JSON-LD literacy. Do
not assume appetite for deep command-line work.

State prerequisites, outcomes, and constraints that affect use. Prefer an
agentic workflow (install a skill, supply a path, approve what the agent asks)
whenever that path exists. Reserve low-level CLI or config detail for cases
with no agentic path, or for pages whose contract is that interface (for
example the MCP server tool shapes).

Keep repository development, release, and publication workflows in Project.

# Discover the query service

Expose a service description that standards-aware clients can obtain from the
endpoint. This lets clients identify the query service from its address and
connect using their discovery behavior.

Verify discovery with a client that uses service descriptions. The [client
documentation](../../reference/clients/index.md) gives Comunica an explicit
endpoint source type.

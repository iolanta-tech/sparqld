# Install the pluglet on Python 3.11 and 3.12

The Python package currently requires Python 3.13 or later. Broaden pluglet
compatibility so MkDocs projects on Python 3.11 and 3.12 can install it.

Verify package installation and a documentation build on each supported
version. Check dependency constraints as part of that compatibility work.

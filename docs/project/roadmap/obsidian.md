# Query a watched directory from Obsidian

Provide an Obsidian plugin workflow for querying RDF in a watched directory.
Users should be able to run SPARQL from their vault and inspect the answer
while sparqld tracks file changes.

Verify the workflow with a vault example, including a query after a source file
changes.

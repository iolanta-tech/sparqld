Use the native `sparqld` Python API for MkDocs macro queries. Install it as a dependency of `mkdocs-macros-sparqld` so ordinary builds do not need a separate server or binary.

## Acceptance criteria

- Query the shared Rust engine through the Python package, reusing a loaded dataset per directory during a build.
- Preserve existing macro behavior, result rendering, diagnostics, and query semantics. Define and test refresh behavior for `mkdocs serve` and cleanup across builds.
- Preserve a way to run HTTP endpoint examples, including the existing `sparqld_port` and endpoint helper contracts or a documented migration for their users.
- Test a clean installation, a strict MkDocs build, multiple directories, query failures, and live reload. Inspect rendered documentation in Chromium through Playwright.
- Update installation and integration documentation and run the required MkDocs review.

Prerequisite: https://github.com/iolanta-tech/sparqld/issues/41.

Add integration coverage that loads anonymized source files and queries the real engine through both HTTP and stdio MCP. This is deferred work.

Acceptance:
- Verify SELECT, ASK, CONSTRUCT and DESCRIBE results, malformed-query errors, and update rejection through both interfaces.
- Verify that a triple repeated across source files contributes once to the default union, while explicit GRAPH matches preserve source graph identity.
- Preserve legitimate duplicate solution bindings from joins, equal projected values and multivalued metadata.
- Cover OPTIONAL plus correlated NOT EXISTS: missing and mixed statuses, multiple companies, self/other awaiting-response holds, blockers and submitted applications. Keep fixtures synthetic.
- Use semantic assertions and deterministic checks in CI; keep timing/scaling experiments in a separate bounded benchmark.
- When query-timeout is implemented, add HTTP/MCP parity checks for SELECT/ASK/graph timeouts, discarded partial results, a subsequent successful query, independent concurrent deadlines, and dataset access being released after cancellation.

Existing tests/mcp.rs provides a starting point. Exercise the loader and public interfaces rather than replacing the query engine with mocks. The default-union correctness assertion should expose the currently known upstream defect until that dependency fix is adopted.

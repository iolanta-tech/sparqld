# Query cached remote Linked Data

Combine local data with cached Linked Data obtained from explicitly approved
remote hosts. Establish the approval policy through the [project configuration
goal](configuration.md) before adding remote access.

Verify local and cached remote facts in one query. Check that remote requests
follow the configured host policy.

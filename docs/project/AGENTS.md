# Project documentation guidance

## Project persona

Write for a potential contributor or maintainer evaluating, modifying, testing,
releasing, or publishing `sparqld`. They work from the repository and need
project decisions, roadmap context, and development workflows. Keep end-user
operating contracts in Reference.

State the contributor action, the repository context that makes it necessary,
and the verification that establishes completion. Do not describe implementation
details that do not affect a contributor decision or action.

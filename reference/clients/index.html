    Clients

    These command-line tools are exercised against the current sparqld binary whenever this documentation is built.

    SPARQL clients

    • sq Recommended

      sq -e http://127.0.0.1:7737/ graphs

      Use an endpoint URL directly, or configure the endpoint and prefixes for concise repeated queries.

    • Apache Jena rsparql

      rsparql --service http://127.0.0.1:7737/ --query query.rq

      Sends a query file through Jena's SPARQL Protocol client.

    • Comunica

      comunica-sparql sparql@http://127.0.0.1:7737/ -f query.rq

      The sparql@ prefix identifies the source as an endpoint without requiring Service Description discovery.

    • RDFLib sparqlquery

      sparqlquery http://127.0.0.1:7737/ --queryfile query.rq

      Queries the endpoint with RDFLib's Python command-line client.

    Direct HTTP tools

    • curl

      Send SPARQL Protocol requests directly over HTTP. See the curl examples for GET and POST request forms.
